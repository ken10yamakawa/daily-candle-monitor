# Daily Candle Stock Monitor (日足監視＆市場スキャナーWebアプリケーション)

日本株・米国株・暗号資産・為替（FX）の日足をリアルタイムに監視し、ゴールデンクロスやボリンジャーバンド突破、RSI買われすぎ/売られすぎ、新高値ブレイクアウトなどのテクニカルシグナルを自動検知・通知するWebダッシュボードアプリケーションです。

**PCはもちろん、スマートフォン（iPhone / Android）のブラウザからも滑らかに閲覧・操作できます。**

---

## 📱 スマートフォンでの閲覧方法

1. **PC側でアプリを起動**:
   ```bash
   python run.py
   ```
2. **ターミナルに表示されるMobile用URLを確認**:
   ```text
   [PC Access]     http://localhost:8000
   [Mobile Access] http://192.168.0.81:8000
   ```
3. **スマホをPCと同じWi-Fiに接続**し、スマホのブラウザ（Safari / Chrome等）で上記URL（例: `http://192.168.0.81:8000`）を開くだけで、専用のモバイルUIで利用できます。

---

## 🚀 主な機能

1. **📱 モバイル完全対応（レスポンシブ＆ボトムナビゲーション）**
   - 画面下部にモバイル専用のボトムバー（📈 チャート / 📋 銘柄一覧 / ⚡ スキャナー / 🔔 アラート）を搭載
   - スマホ縦画面に最適化された TradingView タッチ操作（ピンチズーム・スクロール）
   - ノッチ・セーフエリア対応のフルスクリーンUI

2. **⚡ 市場スキャナー (日経225 / NASDAQ 100 / 暗号資産・為替)**
   - **対象市場**: 日経225（日本株主要86銘柄）、NASDAQ 100（米国主要ハイテク45銘柄）、主要暗号資産・為替
   - **流動性フィルター**: 最小出来高（10万株以上 / 50万株以上 / 100万株以上）で薄商い銘柄を排除
   - **特異値動き抽出**:
     - 🚀 **出来高急増（20日平均比 1.5倍〜3.0倍以上）＋ 上昇ブレイク**
     - 🎯 **直近20日 新高値更新 / 新安値更新**
     - ✨ **ゴールデンクロス / デッドクロス (5日線 x 25日線)**
     - 🔥 **前日比急騰 / 急落 (±4%以上)**
     - 🌊 **ボリンジャーバンド +2σ 突破**
     - ⚡ **RSI 極値 (75以上 / 25以下)**
   - **ワンクリック操作**: 抽出された銘柄をタップして即座にチャート分析 ＆ チェックボックスで一括ウォッチリスト追加

3. **プロ仕様インタラクティブチャート**
   - **TradingView Lightweight Charts** を採用した滑らかなローソク足チャート
   - 移動平均線（SMA 5日 / 25日 / 75日）
   - ボリンジャーバンド (±2σ)
   - RSI (14日) サブチャート (買われすぎ70 / 売られすぎ30ライン)
   - 出来高 (Volume) ヒストグラム
   - 期間切り替え（1M, 3M, 6M, 1Y, 2Y, 5Y）

4. **自動シグナル検知＆アラート機能**
   - ウォッチリスト全銘柄を3分ごとにバックグラウンド自動スキャン ＆ 手動即時更新ボタン
   - ブラウザ通知トースト＆Web Audioサウンドチャイム
   - アラート履歴の保存・既読管理

---

## 🛠 技術スタック
- **Backend**: Python 3.13 / FastAPI / Uvicorn (0.0.0.0 ホストバインド) / SQLite
- **Data Source**: `yfinance` (マルチスレッド一括ダウンロード対応)
- **Technical Analysis**: `pandas`, `numpy`
- **Frontend**: HTML5, Vanilla CSS (Mobile Responsive), Modern JavaScript
- **Charting**: TradingView Lightweight Charts (v4)
